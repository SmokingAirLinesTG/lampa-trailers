# Лента трейлеров для Lampa

Плагин для [Lampa](https://github.com/yumata/lampa-source). Показывает YouTube-трейлеры фильмов выбранного жанра на весь экран, листать их можно как шортсы.

- В меню Lampa появляется пункт **«Лента трейлеров»**. В нём выбираешь «Популярное» или жанр.
- **▲ / ▼** — предыдущий или следующий фильм.
- **OK** — карточка фильма в Lampa, оттуда его можно запустить.
- **Назад** — выход. Если вернуться из карточки, лента продолжит с того же фильма.

Чтобы листание было мгновенным, лента готовит 10 следующих фильмов заранее: трейлер, логотип, постер и фон. При перелистывании сразу, из кеша, появляется кадр-обложка фильма, его логотип и описание, а трейлер плавно проявляется поверх, как только YouTube начал играть. Так устроено на Netflix, и задержка старта не видна. Три следующих трейлера заранее открыты в невидимых плеерах без воспроизведения (`autoplay=0`): YouTube загружает сам плеер, но не скачивает и не декодирует видео, поэтому текущий ролик не дёргается. У ТВ один-два аппаратных декодера. Плееры готовятся по одному, когда текущий уже играет, пройденные выгружаются.

Фильмы берутся из TMDB: популярные с не меньше чем 50 голосами. Трейлер выбирается сначала на языке интерфейса TMDB, потом английский, тизер — только если трейлера нет. Фильмы без трейлера на YouTube пропускаются, ролики, которые YouTube запрещает встраивать, тоже. Видео идёт через официальный YouTube IFrame API, подключённый прямо в страницу Lampa, без промежуточной страницы. Плеер в натуральную величину экрана, поэтому YouTube выдаёт 1080p, а не 4K. Если YouTube отказывает странице Lampa (ошибка 153, у страницы нет адреса-источника), лента переходит на запасную страницу-плеер `yt.html`, уже без предзагрузки. `trailers-feed.js` — только загрузчик, который каждый раз берёт свежий `feed.js`: так обновления доходят до ТВ сразу, без ожидания 10-минутного кеша GitHub Pages.

## Установка

Настройки → Расширения → Добавить плагин:

```
https://smokingairlinestg.github.io/lampa-trailers/trailers-feed.js
```

Если экранная клавиатура Lampa не принимает ввод, переключи «Настройки → Остальное → Тип клавиатуры» на «Системная», а после установки верни обратно.
