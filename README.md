# Лента трейлеров для Lampa

Плагин для [Lampa](https://github.com/yumata/lampa-source). Показывает YouTube-трейлеры фильмов выбранного жанра на весь экран, листать их можно как шортсы.

- В меню Lampa появляется пункт **«Лента трейлеров»**. В нём выбираешь «Популярное» или жанр.
- **▲ / ▼** — предыдущий или следующий фильм.
- **OK** — карточка фильма в Lampa, оттуда его можно запустить.
- **Назад** — выход. Если вернуться из карточки, лента продолжит с того же фильма.

Чтобы листание было мгновенным, лента готовит 10 следующих фильмов заранее: трейлер, логотип, постер и фон. Два ближайших трейлера уже открыты в невидимых плеерах: они стартуют без звука, на первом кадре встают на паузу, и после перелистывания у текущего просто включается звук. Пройденные плееры выгружаются. Живых плееров не больше трёх, потому что каждый YouTube-iframe занимает около сотни мегабайт, а у ТВ 1,8 ГБ памяти и один-два аппаратных видеодекодера.

Фильмы берутся из TMDB: популярные с не меньше чем 50 голосами. Трейлер выбирается сначала на языке интерфейса TMDB, потом английский, тизер — только если трейлера нет. Фильмы без трейлера на YouTube пропускаются, ролики, которые YouTube запрещает встраивать, тоже. Видео идёт через собственную страницу-плеер `yt.html`. Она кадрирует плеер так же, как bridge Lampa, но умеет предзагрузку без звука. `trailers-feed.js` — только загрузчик, который каждый раз берёт свежий `feed.js`: так обновления доходят до ТВ сразу, без ожидания 10-минутного кеша GitHub Pages.

## Установка

Настройки → Расширения → Добавить плагин:

```
https://smokingairlinestg.github.io/lampa-trailers/trailers-feed.js
```

Если экранная клавиатура Lampa не принимает ввод, переключи «Настройки → Остальное → Тип клавиатуры» на «Системная», а после установки верни обратно.
